      cp .env.example .env
      vi .env

  2️⃣  检查配置
      ./check-config.sh

✨ 核心功能

  ✅ 实时监控指定 Twitter 用户
  ✅ 新推文立即推送到 Telegram
  ✅ 支持 HTTP/HTTPS 代理
  ✅ 自动去重，避免重复通知
  ✅ 24/7 后台运行
  ✅ 自动重启，稳定可靠
  ✅ 一键部署，简单易用

🚀 快速命令

  本地测试：        npm start
  配置检查：        ./check-config.sh
  测试连接：        ./test-connection.sh
  一键部署：        ./quick-deploy.sh
  
  远程日志：        ssh root@ip "pm2 logs twitter-monitor"
  远程重启：        ssh root@ip "pm2 restart twitter-monitor"

🔑 需要的 Token

  1. Twitter Bearer Token
     → https://developer.twitter.com
  
  2. Telegram Bot Token  
     → 在 Telegram 搜索 @BotFather
  
  3. Telegram Chat ID
     → 在 Telegram 搜索 @getidsbot

📦 项目文件说明

  核心代码：
    index.js          程序入口
    monitor.js        监控逻辑
    twitterApi.js     Twitter API
    telegramBot.js    Telegram 通知
    config.js         配置管理

  部署脚本：
    quick-deploy.sh   一键部署（推荐）
    deploy.sh         服务器部署
    update.sh         应用更新
    test-connection.sh 连接测试
    check-config.sh   配置检查

  配置文件：
    .env              环境变量（需配置）
    .env.example      配置模板
    ecosystem.config.js PM2 配置

❓ 常见问题

  Q: 如何开始？
  A: 查看 QUICKSTART.md，5 分钟上手

  Q: 部署失败？
  A: 运行 ./test-connection.sh 检查服务器

  Q: 收不到通知？
  A: 检查 Telegram Bot Token 和 Chat ID

  Q: 如何更新？
  A: 在服务器运行 ./update.sh
